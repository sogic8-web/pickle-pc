    GitHub 연결

    프롬프트와 파일은 모두 내 비공개 저장소에만 저장됩니다. 이 사이트에는 서버가 없습니다.

    1. 토큰을 발급합니다.

      아래 두 가지 중 편한 것을 쓰면 됩니다. Fine-grained 방식이 더 안전합니다.

      Fine-grained 토큰 발급 (권장) Classic 토큰 발급 (repo)
      • Fine-grained: Repository access → Only select repositories → pickle-workspace 선택, Permissions → Contents: Read and write 만 켜면 됩니다.
      • Classic: scope에서 repo 하나만 체크하면 됩니다.
      • 만료 기간은 원하는 만큼 짧게 잡아도 되고, 만료되면 새 토큰으로 바꿔 넣으면 됩니다.
    2. 발급한 토큰을 아래에 붙여넣고 저장합니다.

      토큰은 localStorage(이 브라우저)에만 보관되며, 공개 저장소나 외부로는 절대 나가지 않습니다. 공용 PC에서는 쓰지 마세요.

    저장소

    화면 코드(공개)와 데이터(비공개)가 분리되어 있습니다.

    기본값은 sogic8-web / pickle-workspace 입니다. 다른 저장소를 쓰려면 위에서 바꾸세요.
