    연결 방법

    처음 한 번만 하면 됩니다. 3단계면 끝납니다.

    1

    토큰 발급

    Fine-grained 방식이 더 안전합니다. 저장소는 pickle-workspace 하나만 고르세요.

    Fine-grained (권장) Classic
    • Repository access → Only select repositories → pickle-workspace
    • Permissions → Contents: Read and write 만 켜기
    2

    토큰 저장

    발급한 토큰을 위 입력란에 붙여넣고 저장을 누르면 이 브라우저에만 보관됩니다.

    • 공개 저장소나 외부로 전송되지 않습니다.
    • 공용 PC에서는 사용 후 토큰 삭제를 눌러 주세요.
    3

    연결 확인

    연결 테스트로 저장소 접근과 쓰기 권한을 함께 확인합니다. 처음 연결하면 inbox/ · outbox/ 폴더가 자동으로 만들어집니다.

    • 저장소가 공개 상태면 화면에 경고가 표시됩니다.
    • 토큰이 만료되면 새 토큰으로 바꿔 넣으면 됩니다.

    저장소

    화면 코드(공개)와 데이터(비공개)가 분리되어 있습니다.

    기본값은 sogic8-web / pickle-workspace 입니다. 다른 저장소를 쓰려면 위에서 바꾸세요.
